# Project Structure Document

```
my-family/
├── public/
│   ├── config.json            # Default application fallback configuration
│   ├── manifest.json          # PWA web app manifest
│   ├── sw.js                  # PWA Service Worker generated by next-pwa
│   └── icons/                 # 192x192 and 512x512 PNG app icons
├── src/
│   ├── app/                   # Next.js App Router routes
│   │   ├── page.tsx           # Home Dashboard page
│   │   ├── admin/             # Local Admin Panel page (/admin)
│   │   ├── backup/            # Dedicated Backup System page (/backup)
│   │   ├── families/          # Family management list & detail pages
│   │   ├── members/           # Member list & profile pages
│   │   ├── offline/           # PWA offline fallback route (/offline)
│   │   ├── settings/          # Settings page (/settings)
│   │   ├── tree/              # Interactive Family Tree page (/tree)
│   │   └── layout.tsx         # Root layout & providers
│   ├── components/            # UI & feature components
│   │   ├── ads/               # Advertisement Manager component
│   │   ├── backup/            # Backup Manager component
│   │   ├── layout/            # Navigation, Headers, System Banners
│   │   ├── pwa/               # PWA Install Button component
│   │   └── ui/                # Reusable UI primitives (Button, Card, Dialog, Badge, Input, Select)
│   ├── database/              # Dexie.js IndexedDB layer
│   │   ├── index.ts           # Dexie database instance & table schemas
│   │   ├── backup.ts          # Backup export, import, parse & restore functions
│   │   ├── config.ts          # App configuration load, save & reset functions
│   │   └── crud.ts            # Family and Member CRUD operations
│   ├── hooks/                 # Custom React hooks (useTheme, useAppConfig, useDatabase)
│   ├── styles/                # Global CSS styles & Tailwind configuration
│   ├── types/                 # TypeScript interfaces & Zod schemas (schema.ts)
│   └── utils/                 # General utility functions
├── docs/                      # Project documentation
├── next.config.ts             # Next.js & PWA plugin configuration
├── package.json               # Package dependencies & scripts
└── tsconfig.json              # TypeScript compiler configuration
```
